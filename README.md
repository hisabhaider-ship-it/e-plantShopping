# Paradise Nursery - Shopping Application

Paradise Nursery is an e-commerce React application that allows users to browse through a collection of houseplants, view details, and manage their shopping cart using Redux Toolkit.

## Features
- **Landing Page:** Welcome screen with background image and "Get Started" button.
- **Product Listing:** 18 unique houseplants categorized into 3 distinct sections (Air Purifying, Aromatic, Low Maintenance).
- **Interactive Cart:** Add to cart buttons disable upon selection and increment the global navbar cart counter.
- **Cart Management:** Dynamically calculate item subtotals and grand totals, adjust item quantities, remove items, and navigate between views.
